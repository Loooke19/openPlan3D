# 岐阜医院 3D 导航修复

基于 kit-wt `5f77cdc`、后端 `1ceb251` 的累计补丁；`fe.patch`、`be.patch` 可直接应用到干净副本。未推送。

PDF 对照：P1 3F 西楼梯口的“药剂存放处”框线被配对成墙，并在端点延长时伸入过道（`wall-131/132`）；手画续线 `wall-ov-12` 接在同一误识别线后。P1 2F 儿科／收费处旁 `wall-181` 被延至门洞外。P2 2F `wall-108/109`、3F `wall-101/102`、4F `wall-90` 把楼梯踏步／家具横线当作整高墙并延入西楼梯口。P3 1F 门厅 `wall-112`、2F 东楼梯口 `wall-64/67/68` 是踏步／井道边线误识别。P2 5F `wall-73/74/75` 和 `wall-151` 经 PDF 复核是防火玻璃窗、门边及办公室真实墙，保留。

修复规则统一按走廊面、楼梯位置、墙端连接、线长和厚度识别侵入段；误识别段只保留零高度的房间拓扑边界，避免真实房间、门厅及外圈地面丢失。`wall-181` 只把伸出门洞的尾段转为零高度边界。3D 墙体、陈设和导航碰撞均忽略这些边界。
