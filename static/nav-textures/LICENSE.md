# Surface textures

CC0 1.0 from ambientCG (https://ambientcg.com), downsampled to 512 px and converted
(detail = luminance centred on mid-grey, so the hospital palette colours stay in code):

- floor-*: Terrazzo009 (https://ambientcg.com/view?id=Terrazzo009)
- wall-*: PaintedPlaster017 (https://ambientcg.com/view?id=PaintedPlaster017)
- wainscot-*: Plastic010 (https://ambientcg.com/view?id=Plastic010)
